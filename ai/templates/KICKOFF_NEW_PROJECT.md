# Kickoff: New Project (renamed)

Last Updated: 2026-05-21

**This file was renamed in v1.2.0** to better reflect the kit's
new mental model: the repo is a "solution" that holds N "projects."

Use one of these instead:

- 🌱 **New repo + first project** → `/ai/templates/KICKOFF_NEW_SOLUTION.md`
- ➕ **Add a project to an existing solution** → `/ai/templates/KICKOFF_ADD_PROJECT.md`

The new wizards are tighter (3 picks + 1 free-text) and modeled on
the new-project dialog you already know from VS Code / Visual
Studio / Rider / IntelliJ / Xcode.

This redirect file is kept for one release (v1.2.x) so existing
bookmarks and READMEs keep working. It will be deleted in v1.3.0.
